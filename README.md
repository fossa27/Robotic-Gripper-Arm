# Robotic-Gripper-Arm
Hello and welcome to my custom Robotic Gripper Arm! I did this project to learn more about CAD design, 3D printing, and arduino. The design is a based on a very common gripper arm design, but then customized to my specifications and limitations, making it uniquely mine. Mainly it has a multistable gripper, reducing the energy required to grip an object. The entire design was made on Onshape, with the code from Arduino IDE. Majority of the parts are 3D printed with PLA, with the gripper being 95A TPU. This project also uses basic 9g servo motors. All other electrical components came from the UNO R3 Project Super Starter Kit.
